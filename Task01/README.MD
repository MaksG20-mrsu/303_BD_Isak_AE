# Лабораторная работа №1

## Структура файлов данных

Каталог `Task01` содержит файлы исходных данных.

### `ratings.csv`

Файл содержит оценки пользователей за фильмы.

| Поле | Описание |
|---|---|
| `userId` | идентификатор пользователя |
| `movieId` | идентификатор фильма |
| `rating` | оценка фильма |
| `timestamp` | время выставления оценки |

### `movies.csv`

Файл содержит информацию о фильмах.

| Поле | Описание |
|---|---|
| `movieId` | идентификатор фильма |
| `title` | название фильма |
| `genres` | жанры фильма |

### `tags.csv`

Файл содержит пользовательские теги для фильмов.

| Поле | Описание |
|---|---|
| `userId` | идентификатор пользователя |
| `movieId` | идентификатор фильма |
| `tag` | текст тега |
| `timestamp` | время добавления тега |

### `users.txt`

Файл содержит информацию о пользователях.

### `genres.txt`

Файл содержит информацию о жанрах.

### `occupation.txt`

Файл содержит информацию о профессиях пользователей.

### `ratings_count.txt`

Файл содержит минимальный и максимальный идентификаторы пользователей и количество записей с каждым из этих идентификаторов.

### `sqlite.txt`

Файл содержит версию установленной SQLite и список доступных режимов вывода данных.
